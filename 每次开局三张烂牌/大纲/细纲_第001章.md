# 第 1 章：停更两年，世界催我上线

- 核心事件：欠租停更的周恕在出租楼异常封闭时，被“失序构筑”强制拉入第一局。
- 字数目标：2200 字
- 阶段位置：开篇期第 1 章；立困境、人设与核心卖点。
- 单元ID/位置：L1-01；建立期待。
- 目标情绪：对颓废生活的苦笑→异常降临的紧张→三选一出现的惊奇。
- 主角目标/关键选择：把最后一单外卖送完交房租；停电后选择下楼找唐小满，而非锁门等待。
- 章节定位：高压。
- 本章结构公式：欠租催缴→楼道异常→主动找人→三选一降临。
- 章首钩子：反常结果式—停更两年的账号突然显示“正在直播”。
- 爽点：无显性兑现；核心期待是三个古怪选项中如何活命。
- 本章禁止提前释放：不解释裂场、事务署和系统来源。
- 契约风险：契约安全。

## 内容概括（五段式）
- 起因：房东催租，周恕接下暴雨夜最后一单。
- 发展：送餐回楼后，发现门牌循环、手机直播自动开启。
- 转折：隔壁传来唐小满敲墙求救，周恕仍选择出门。
- 高潮：楼道灯全部变红，楼梯间长出第二个向下入口。
- 结尾：面板弹出三条随机增幅，倒计时十秒。

## 情节安排（多线）
- 主线推进：周恕进入首个裂场。
- 辅线推进：旧事故以他拒看直播后台的动作暗示。
- 事件线 / 任务线：送单→回楼→异常→救邻居。
- 任务卡点：门牌循环卡住寻人路线，服务设定与选择压力。
- 感情线 / 关系线：无显性感情；周恕与唐小满从疏离邻居转为主动救援。
- 逻辑线：欠租接单→异常封楼→听见求救→主动出门→被系统判定入场。

## 人物关系和出场顺序
- 出场顺序：周恕、房东语音、唐小满。
- 人物关系变化：互相欠小钱的邻居→周恕愿意冒险找她。
- 视角/信息差：读者与周恕都不知道裂场；面板称其“再次入场者”，周恕没注意。
